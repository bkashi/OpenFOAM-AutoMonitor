Run from the OPenFOAM case directory. E.g.:<br>

```bash
python3 ~/OpenFOAM/foamMonitor.py
```

Prerequisites:
- matplotlib
- pandas


💡 See "function" file (place in system directory) for example entries for monitored quantities.<br>
<br>
Tested with OpenFOAM 12.
