# Graphical convergence monitor for OpenFOAM.<br>
- Automatically plots all data generated by the solver for monitoring.
- One clock to switch between montired quantities.
- Shows current value for all quatities.
<br>

<br>
<br>

Run from the OPenFOAM case directory. E.g.:<br>

```bash
python3 ~/OpenFOAM/foamMonitor.py
```

Prerequisites:
- matplotlib
- pandas


💡 See "function" file (place in system directory) for example entries for monitored quantities.<br>
<br>
Tested with OpenFOAM 12.
